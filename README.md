# cynelo-ott-platform

> **Demo Content Notice:** Cynelo uses movie metadata and trailers for demonstration purposes. Full-length copyrighted films are not hosted or distributed by this project.
>
> **Project Purpose:** Cynelo is built as a full-stack OTT streaming platform to demonstrate end-to-end web application development, including frontend UI, backend APIs, authentication, database management, content discovery, user interactions, and video playback.
